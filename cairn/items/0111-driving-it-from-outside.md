The socket API can be asked things. This is the half that lets a program use
it: submit a prompt to an agent, wait for one to block, wait for a line of
output, and read a machine-readable description of the whole surface.

dirk's claim is that it knows what its sessions are for. An agent that can
drive its own multiplexer is what that claim is worth.
