## Problem
The sidebar is the reason dirk exists rather than tmux. It has to answer 'what
is open, and where' at a glance, and be usable with the pointer alone.

## Acceptance criteria
- [x] Static pages as singletons above the rule, with jump keys
- [x] Projects fold and unfold on click
- [x] Workspaces show agent state in the spine column
- [x] Every row is a click target, registered as it is drawn
